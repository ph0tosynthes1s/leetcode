# LeetCode Repo

Репозиторий с моими ежедневными решениями задач **LeetCode** на четырех языках программирования: **PHP**, **JavaScript**, **Go** и **Python**.

## Я это делаю чтобы:
- развивать алгоритмическое мышление;
- лучше понимать структуры данных;
- изучать идиоматичный код на разных языках;
- отслеживать собственный прогресс и поддерживать дисциплину.

## Структура репозитория:
```text
.
├── ez/
│   ├── 0001-two-sum/
│   │   ├── php/
│   │   ├── javascript/
│   │   ├── go/
│   │   └── python/
│   └── ...
├── mid/
├── hard/
└── README.md
```

Каждая задача содержит реализацию на одном или нескольких языках программирования. По мере изучения новых подходов решения могут дополняться или улучшаться.

## Принципы:
- решаю задачи каждый день;
- чистый, понятный и идиоматичный код;
- сравниваю реализацию на разных языках;
- комментирую используемые подходы.

## Для чего я делаю это в гит:
- фиксирую свой прогресс;
- поддерживаю ежедневную практику;
- стимулирую себя писать более качественные решения;.
